# ByeBlocking

> Локальный VPN-клиент для Windows

## 📖 О проекте

**ByeBlocking** — это приложение для Windows, разработанное на **C# и .NET**, предназначенное для создания локального VPN-туннеля и управления сетевыми подключениями.

Программа предоставляет удобный интерфейс для настройки сетевых параметров, мониторинга соединений и управления маршрутизацией трафика.

## ✨ Возможности

* Современный интерфейс Windows
* Создание локального VPN-туннеля
* Мониторинг сетевой активности
* Просмотр статистики соединений
* Настройка DNS-серверов
* Управление маршрутами сети
* Автоматический запуск вместе с Windows
* Низкое потребление ресурсов
* Поддержка Windows 10 и Windows 11

## 🛠 Используемые технологии

* C#
* .NET 8
* WPF
* Windows Networking API

## 📦 Системные требования

* Windows 10 / 11
* .NET 8 Runtime
* 64-битный процессор
* Не менее 100 МБ свободного места на диске

## 🚀 Установка

### Готовая сборка

1. Перейдите в раздел Releases.
2. Скачайте последнюю версию программы.
3. Запустите установщик.
4. Следуйте инструкциям мастера установки.

### Сборка из исходного кода

```bash
git clone https://github.com/damiry947/ByeBlocking.git
cd ByeBlocking
```

Откройте решение в Visual Studio 2022 и выполните сборку проекта.
