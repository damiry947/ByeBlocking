# ByeBlocking 🚀

Легковесный и высокопроизводительный локальный SOCKS5 прокси-сервер на языке Go, созданный для перехвата и маршрутизации сетевого трафика. Этот проект — первый шаг к разработке собственных продвинутых инструментов для обхода систем DPI.

Проект распространяется под свободной лицензией **MIT**.

## Особенности

- **Чистый Go**: Написан без использования тяжелых внешних зависимостей, только стандартная библиотека Go.
- **Поддержка SOCKS5**: Реализация стандарта RFC 1928 (режим без аутентификации).
- **Асинхронность**: Высокая скорость работы и обработка сотен одновременных соединений благодаря легковесным горутинам (goroutines).
- **Готов к модификации трафика**: Работает как полноценный посредник (middleman), что позволяет в будущем легко внедрить функции дробления пакетов (splitting), изменения порядка (disordering) и подмены заголовков.

## Быстрый запуск

### Требования

- Установленный [Go](https://go.dev) версии 1.20 или выше.

### Сборка проекта

Склонируйте репозиторий и скомпилируйте исполняемый файл:

```bash
git clone https://github.com
cd ByeBlocking
go build -o byeblocking main.go
```

### Запуск сервера

Запустите прокси-сервер на своем компьютере:

```bash
./byeblocking
```

После этого сервер начнет слушать входящие соединения по адресу `127.0.0.1:1080`.

## Как направить трафик через ByeBlocking

Так как SOCKS5-прокси по умолчанию не перехватывает трафик всей операционной системы автоматически, приложения нужно настроить вручную:

1. **Telegram / Discord**: Откройте Настройки -> Продвинутые настройки -> Тип подключения -> Прокси SOCKS5. Укажите хост: `127.0.0.1`, порт: `1080`.
2. **Браузеры (Chrome / Firefox / Яндекс)**: Используйте расширения вроде *Proxy SwitchyOmega* или настройте прокси в параметрах системы, указав `socks5://127.0.0.1:1080`.
3. **Глобальный перехват трафика**: Для принудительного направления всех программ через прокси используйте утилиты класса *Proxifier* (на Windows) или настройте локальный TUN-интерфейс.
